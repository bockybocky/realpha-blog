## 這篇在講什麼

我一直有一個小困擾：語音辨識這種活需要顯示卡，而我這台機器沒有像樣的卡。上個月我用處理器硬跑過一次，十分半鐘的錄音跑了十八分半，技術名詞還聽錯一堆。當時的結論是先用雲端服務，把買卡的錢省下來。

昨天（2026-08-31）我把另一條路走通了：不買卡，按秒租一張。用的是 RunPod 這個平台，工具是朋友 Fred 寫的 srt-skill。這篇想跟你分享實際跑完之後我怎麼看「租」和「買」這件事，還有 RunPod 除了語音辨識以外能拿來做什麼。

先說結論：這不是效能之爭，是用量之爭。

## 先講昨天的數字

一段測試音檔，四輪嘗試（前三輪在踩坑，後面會講），第四輪順利辨識出 38 段文字。四輪加起來用了 567 秒的 GPU 時間，帳單約 3.4 元台幣（RunPod 儀表板，2026-08-31）。換算成每小時，安全雲的 4090 是 0.74 美元，約 24 元台幣；社群雲更便宜，0.34 美元，約 11 元。帳戶裡本來儲值了 15 美元，這樣算下來夠我跑幾百段。

Fred 在工具文件裡寫的估算是一段 50 分鐘的錄音大約 0.05 到 0.15 美元，我跑出來的數字跟他對得上。

## 租和買，兩條路各自的形狀

我把兩邊的成本攤在同一張表上（價格來自 RunPod 官方定價頁，2026-09-01 查；顯示卡價格用掄錘者影片裡「兩張卡一萬多人民幣」的口徑，約 1,400 美元）：

| | 租（RunPod） | 買（本地一張卡） |
|---|---|---|
| 前期 | 儲值幾美元就能開始 | 一萬多人民幣一次付清 |
| 計費 | 按秒，跑完機器砍掉就停 | 電費、折舊、佔桌面 |
| 4090 一小時 | 0.34 美元（社群雲）到 0.74 美元（安全雲） | 折舊攤到每小時，看你跑幾小時 |
| 等待 | 每次開機要等一到三分鐘，偶爾連不上要換機 | 隨開隨用 |
| 斷線那天 | 平台掛了你就停 | 你自己的機器，跟網路無關 |
| 最貴的機器 | H100、B200 也租得到 | 買不起，也用不到 |

用 4090 社群雲的價格算：一萬多人民幣可以租大約 4,100 小時。如果你每天跑兩小時，要五年多才追平；每天跑八小時，一年半。五年後的顯示卡是什麼樣子，我們都知道。

![兩條線從左往右：一條水平的粗線代表買卡一次付清的固定成本，一條從零出發的斜線代表租用累積的費用；兩線交叉點標著「約四千小時」，交叉點左邊寫租划算、右邊寫買划算](/figures/rent-vs-buy-crossover.svg)

所以問題從來不是「哪個便宜」，是「你在交叉點的哪一邊」。我自己一個月跑不了幾次，離交叉點很遠，租是明顯的答案。掄錘者那種每天跑十幾小時、還要生圖生影片的人，在另一邊。

上個月寫本地硬體那篇時，我把買卡講成一份保險：保的是「別人漲價和斷線的時候，我還能動」。這句話今天還成立，只是要補一句：保險要看你有多常需要它。一年遇不到一次斷線的人，付五年保費不划算。

## RunPod 可以拿來做什麼

我這次只用了它最單純的一種用法：開一台機器、跑一個腳本、砍掉機器。它其實有幾種形狀，適合不同的活：

一、一次性的批次工作。像我這次的語音辨識，或是把一批舊照片一次放大、把一整批文件跑一次同樣的處理。開機、跑完、砍掉，只付那幾分鐘。這是我認為最沒有懸念的用法：[Pods 定價頁](https://www.runpod.io/pricing)。

二、試一張你買不起的卡。想知道某個模型在 H100 上跑起來是什麼感覺，租一小時兩三美元，比看評測影片實在。

三、微調模型。訓練型的活通常是幾小時到幾天，跑完就結束，正是「租」的形狀。RunPod 的容器可以自己帶環境，訓練完把權重下載回來就好。

四、Serverless 端點。如果你有一個服務偶爾被打到（例如一個小工具的後端），可以把模型部署成按呼叫計費的端點，沒人用的時候不付錢。這條我沒實跑，只讀了文件：[Serverless 說明](https://docs.runpod.io/serverless/overview)。

五、生圖生影片。掄錘者說這類工作「線上 API 有多少錢都擋不住」，那是講各家生圖服務的 API 價格；直接租一張卡跑開源模型是另一回事，按秒計費、跑多少算多少。我還沒試，先記在這裡。

工具文件與教學都在官方文件站：[docs.runpod.io](https://docs.runpod.io)。

## 常見的本地模型，哪些適合租、哪些適合買

把我這陣子碰過、或在掄錘者影片裡反覆出現的模型排一排，用同一把尺看：它是「跑完就結束」還是「要一直開著」。

| 模型 | 它做什麼 | 我會怎麼跑 |
|---|---|---|
| Whisper large-v3 | 語音辨識，多語言 | 租。語音辨識是批次活，一段錄音幾分鐘就完，正是這次的用法 |
| Breeze（聯發科的中文語音辨識） | 中文語音辨識，台灣口音準 | 租。srt-skill 的雲端路徑目前只支援它 |
| VibeVoice | 輔助辨識，抓英文名詞與同音字 | 目前只能本地跑，走雲端會跳過這一步 |
| Qwen3.8 27B | 通用大模型，本地最強的稠密模型（掄錘者的評價） | 每天當 agent 的腦袋跑長任務就買卡；偶爾用租一小時試試 |
| Gemma 4 26B | 通用大模型，Ollama 一行就能拉 | 同上；srt-skill 的離線校正模式用的就是它 |
| DeepSeek V4 Flash | 線上模型，便宜全能 | 不用租也不用買，走 API。掄錘者的首推 |
| 生圖生影片模型（LTX、MiniMax H3 這一類） | 出圖出片 | 批次出片租一張 48G 的卡；每天出片的人買 |

規則只有一條：要一直開著、每天都在用的東西才值得買；跑完就結束的活，租。模型名字不重要，用量才重要。

## 我踩到的三個坑

寫出來是因為 RunPod 的官方文件都沒提，你照著裝完不代表能跑。

第一，錯誤訊息會指錯兇手。腳本告訴我「SSH 公鑰無效」，還附上正確的檔案路徑。金鑰其實完全沒問題——真正的原因是我機器上沒裝 `jq` 這個小工具，驗證那段程式一跑就整條回非零，於是每一把金鑰都會被判無效。教訓是：錯誤訊息點名誰，先獨立驗誰，再去看產生那句話的程式依賴什麼。

第二，直連的網路端口大約一半機率生不出來。這不是壞掉，是 RunPod 社群雲的常態；Fred 的腳本會等 180 秒後自動換一台，最多試三次。我前三輪有兩輪就是在等這個。

第三，跑完一定要確認機器砍掉了。沒砍就是一直在計費。我每輪都回去 RunPod 網站看 Pods 頁面是不是空的，四輪都是空的。這個習慣比任何省錢技巧都重要。

還有一個 Windows 專屬的坑：Git Bash 會把 `/root/...` 這種路徑自動改成 Windows 路徑，SSH 過去的指令就壞了。解法是只排除那一個前綴，不能整個關掉路徑轉換，關掉會害本機的 ffmpeg 找不到檔。這一條 Fred 已經收進工具的說明。

## 本文協助者：Fred

這篇能寫出來，程式實測是 Fred 做的。他寫的 [srt-skill](https://github.com/fredchu/srt-skill) 把「音檔 → 校正過的台灣繁體文字」做成一條指令，語音辨識可以走本地的 Apple Silicon，也可以像我這樣走 RunPod；我在 Windows 上遇到的坑，都是先在他那邊跑通、再回頭補到說明裡。姊妹工具 [speech-to-prose](https://github.com/fredchu/speech-to-prose) 是同一條管線的另一種輸出格式，附時間戳和電子書。

他的 GitHub 在這裡：[github.com/fredchu](https://github.com/fredchu)。如果你也在做語音轉文字這件事，先看他的，不用從零開始。

一句誠實的話：雲端和本地跑出來的文字不是完全一樣的，Fred 量過，文字差約百分之二，而且不知道哪邊比較對。這個差異穩定存在，不是雜訊。要用雲端請先知道這件事。

## 帶得走的一件事

我看完帳單留下的一句話是：租和買不是選便宜的，是看你在交叉點的哪一邊。我自己是因為算出「五年多才追平」，才放下了買一張卡的念頭。

如果你也在猶豫，我做過一個很小的動作，你可以試試：今晚翻出你上個月真正需要顯示卡的次數——不是想做的，是真的做了的——寫一個數字在紙上，旁邊寫上每次大概幾小時。兩個數字相乘，就是你一個月的用量。寫完就算完成。

如果想再往前一步，拿那個小時數乘上 0.34 美元，跟一張卡的價錢並排看一眼。

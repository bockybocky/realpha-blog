## 這篇在講什麼

「哪個 agent 最好用」大概是現在最常被問的問題。抡锤者八月下旬的影片（約 16 分鐘）沒有用跑分回答，是把三個工具丟進自己論壇的真實工作裡：開發皮膚、修 bug、日常運維、擋攻擊。答案不是一個名字，是一張座位表——這剛好接上我昨天寫的那篇：管一群 agent，先畫組織圖。

## 三個工具，三種性格

Codex：官方出品一年多，不開源，產品成熟度最高。實測開發論壇皮膚的長線任務，自動規劃六步、二十幾分鐘做完；修 bug 一次丟五六個都能處理，還支援直接拖圖片進去排查。缺點是配本地模型時會改過頭——去圓角的任務連不該動的用戶頭像圓角也一起去了。

Hermes：基於 Python，最不起眼也最穩。不手動更新的話能連續跑三週到一個月不出錯。論壇被攻擊那次，講者全程沒動手，它一邊擋攻擊一邊恢復資料，還順便把版主們都不想做的「幫所有帖子打標籤」默默做完。

DeepSeek Harness：開源、生態衝最快（短時間十萬星）、原始碼三家裡寫得最漂亮。但實測翻車：一個 bug 改到講者發火，最後把代碼推上 GitHub 讓 Codex 接手收拾。病因很有意思——它有些內建工具「自己不知道怎麼調用」，明明會處理圖片，卻非要使用者給圖片網址。

![三個工具各站一格：Codex 站開發格、Hermes 站運維格、DeepSeek Harness 站觀察格；每格下面標它贏在哪、輸在哪](/figures/lz-three-agents-seats.svg)

講者的結論原話很直白：現在要推薦就推薦 Codex，日常腳本維護用 Hermes，DeepSeek Harness 前景宏大但還不能算成品，有精力再玩。

## 真正省錢的不是選工具，是排位置

影片裡最值得抄的一手是成本結構。講者把最耗 token 的粗活——讀代碼、長線開發——丟給本地的 Qwen3.8 27B（一張 AMD 7900 XT 驅動，開 128K 上下文），電費以外免費；本地做不動的才交給雲端 DeepSeek V4 Flash 收尾。一整天的中度開發加運維，總共花 30 元人民幣；同樣的量全接高階的 V4 Pro，一天要 100 多元。他自己算：這樣省兩個月，差價就是一張 4090。

代價也講得老實：本地模型慢（同一個任務 Flash 十分鐘、本地半小時）而且理解力差一截（改過頭那次就是本地模型犯的）。所以這不是「本地便宜所以都用本地」，是便宜的先上、貴的收尾——跟我之前寫 RunPod 那篇算的是同一筆帳，只是他把答案做成了每天在跑的日常。

![成本結構對照：左邊一條長槓大部分塗成免費的本地段、尾端一小截雲端段，一天 30 元；右邊整條都是高階雲端，一天 100 多元；兩個月的差額標成一張顯示卡](/figures/lz-cost-split.svg)

還有一個細節我特別留意：三家裡代碼寫得最漂亮的，是實戰裡唯一翻車的。好看的架構和能幹活是兩回事，評工具要看它把事做完沒有，不是看它長得順不順眼——這跟看公司財報是同一個道理，簡報最漂亮的未必是賺錢的那家。

## 帶得走的一件事

我看完當天把自己的工具清單拿出來排了一次位置：每個 AI 工具旁邊寫下兩個字——它是「開發」還是「值班」。開發要聰明，錯了我看得到；值班要穩，因為它出錯時我不在場。排完發現我有一個工具兩邊都掛名，這就是隱患。你今天也可以花五分鐘排一次：一個工具只准站一格，站不進去的那個，先別急著用它。

## 這篇給誰看

你剛開始用 Claude Code 或 Codex，開過那個黑黑的視窗、打過幾個指令，但對「資料夾在哪」「設定檔是什麼」還沒什麼感覺。然後你發現自己想同時開兩個 agent，一個寫程式、一個幫忙看，視窗就開始亂了。這篇是寫給這個階段的你。

我之前寫過兩篇跟 herdr 有關的文章，一篇講我從它借了什麼想法（[herdr：誰在做事、誰卡住了](/blog/herdr-agent-automation/)），一篇講怎麼用手機接手電腦（[Tailscale ＋ Herdr ＋ Moshi](/blog/phone-to-pc-agent-tailscale-herdr-moshi/)）。那兩篇都預設你已經會用，這篇不預設。

## 先弄懂五個詞

後面會一直用到這五個詞，先用白話講一次。已經懂的可以跳過。

- 終端機：那個黑底白字、讓你打字下指令的視窗。Mac 上叫「終端機」，Windows 上常用的是 PowerShell 或 Windows Terminal。Claude Code 和 Codex 都是在這個視窗裡跑的。
- 指令：你在終端機裡打的一行字，按 Enter 就執行。這篇裡凡是放在灰底方框裡的，都是要你貼進終端機的指令。
- 資料夾與工作目錄：資料夾就是你電腦裡放檔案的那個夾子。「工作目錄」是終端機現在站在哪個資料夾裡。你在哪個資料夾打 claude，它就只看得到那個資料夾裡的東西。
- 設定檔：一個純文字檔，程式一啟動會先讀它，決定要用什麼顏色、什麼按鍵。你不改它也能用，這篇的新手部分不碰它。
- agent：一個會自己動手做事的 AI 程式，像 Claude Code、Codex、Gemini CLI。它跑在終端機的一格裡，跟你對話、幫你改檔案。

## herdr 是什麼

一句話：一間給 AI agent 住的辦公室。

你可以這樣想。你是老闆，每個 agent 是一個員工，每個員工坐一個座位。herdr 這間辦公室做三件事：第一，你下班關燈走人，員工照樣工作，你隔天開門一切還在。第二，你一眼就看得出每個員工現在是在做事、在等你點頭、還是做完了在發呆。第三，你不用走到每個座位旁邊講話，可以隔空派工、隔空看結果。

它是開源軟體，用 Apache 2.0 授權，公司叫 Herdr, Inc.，GitHub 上有三萬多顆星。

## 安裝：只講一條路

Mac 或 Linux，打開終端機，貼這一行，按 Enter：

```bash
curl -fsSL https://herdr.dev/install.sh | sh
```

Windows，打開 PowerShell，貼這一行，按 Enter：

```powershell
powershell -ExecutionPolicy Bypass -c "irm https://herdr.dev/install.ps1 | iex"
```

裝完把終端機關掉重開，打這一行：

```bash
herdr --version
```

看到一串版本號，像 `0.8.2`，就是裝好了。看到「找不到指令」，多半是終端機沒重開，關掉再開一次。

其他裝法（Homebrew、手動下載壓縮檔）放在最後的進階段落。

## 第一次打開：看到什麼

在終端機打：

```bash
herdr
```

畫面會變成兩塊。左邊一條窄窄的是側欄，右邊一大塊是你的終端機，跟原本的沒兩樣，可以照常打指令。

![五個由大到小層層相套的方框，從最外的 session 到最內的 agent，前四層是灰色空容器，最內層的 agent 是實心藍色，代表只有它是活的東西](/figures/herdr-five-layers-nested.svg)

herdr 把東西分成幾層，用大樓來想最快：

1. 整棟大樓叫 session，你打 `herdr` 就是走進預設的那棟。新手只會用到這一棟。
2. 樓層叫 workspace（空間），一個專案開一層。
3. 每層裡的房間叫 tab（分頁）。
4. 房間裡的座位叫 pane（窗格），一個座位就是一個終端機。
5. 坐在座位上的人叫 agent。

前四層都是容器，只有第五層是活的。新手階段你只需要會開房間、切座位，其他的以後再說。

## 只要記三個按鍵

herdr 的按鍵都是「先按一個開頭鍵，放開，再按一個字母」。開頭鍵預設是 ctrl 加 b。下面寫 `ctrl+b, c` 的意思是：按住 ctrl 按 b，放開，再按 c。

| 想做什麼 | 按鍵 |
|---|---|
| 開一個新房間（新分頁） | ctrl+b, c |
| 把目前的座位切成左右兩格 | ctrl+b, v |
| 離開辦公室（agent 照跑） | ctrl+b, q |

先只記這三個。其他常用的：ctrl+b 再按 1 到 9 是切房間，ctrl+b 再按 x 是關掉目前這格，ctrl+b 再按 ? 會列出全部按鍵。

## 用鍵盤開第二個 agent

不需要任何腳本。

1. 在右邊那格打 `claude`（或 `codex`），第一個 agent 就開在這格裡。
2. 按 ctrl+b, v。畫面切成左右兩格，游標跳到新的那格。
3. 在新的那格打 `codex`（或再開一個 `claude`），第二個 agent 開好了。

這時看左邊側欄，會出現兩個 agent 的名字，每個名字旁邊有一個狀態。狀態有五種，用「同事在幹嘛」來記：

- working：在做事。
- blocked：在等你。它有事要問你，或要你按一下核准。
- idle：手上沒事，等你派。
- done：背景做完了，你還沒看。
- unknown：認得出是 agent，但看不出在幹嘛。

![兩軸座標，橫軸是程序在動或停下來、縱軸是要不要你出手，working 在左下、blocked 在右上、done 在右中並有一條箭頭指向右下的 idle 標著看過了，unknown 被畫在座標外的虛線框](/figures/herdr-agent-states-two-axes.svg)

最要看的是 blocked。它的意思是有一個同事在等你，你不去它就一直停在那裡。側欄就是為了讓你不用一格一格點開看，掃一眼就知道誰在等你。

兩個要小心的：done 不是「結案」，只是「做完了你還沒看」；unknown 不代表做完，只代表看不出來。

## 離開，然後回來

按 ctrl+b, q。畫面回到普通的終端機，但兩個 agent 還在跑。你可以關掉終端機視窗、去睡覺。

隔天打開終端機，打 `herdr`，兩個 agent 還在原來的座位上，該做完的做完了，該等你的還在等你。這是我覺得它最值得裝的一個理由：關燈，人還在裡面加班。

![左右兩格對照，左邊你的視窗連著 server 與三個在跑的 agent，右邊你的視窗變成虛線消失，下面的 server 與三個 agent 一模一樣還在跑](/figures/herdr-detach-server-keeps-running.svg)

一個提醒：電腦重開機的話，座位的擺法會還原，但 agent 本身不會自己復活，要重新打 `claude` 或 `codex`。所以它不是備份。

到這裡，新手要會的都講完了。下面是進階，需要再看。

## 進階：用指令而不是按鍵

等你開始想「讓一個 agent 自動去開另一個 agent」，就要用指令了。herdr 的每個動作都有對應的指令，全部長 `herdr 什麼 什麼` 的樣子。

先切一格，再把 agent 放進去，順序不能反：

```bash
# 1. 在目前這格右邊切一格
herdr pane split --current --direction right --no-focus
# 它會印出一段文字，裡面有新那格的編號，像 w1:p2

# 2. 在那格開一個 agent，取名 reviewer
herdr agent start reviewer --kind codex --pane w1:p2

# 3. 派工，等它做完
herdr agent prompt reviewer "看一下目前的改動，只回報要改的地方" --wait --timeout 120000

# 4. 讀回結果
herdr agent read reviewer --lines 120
```

![左右對照，左邊直接起 agent 卻沒有可放的窗格因此落空，右邊先切出一個空窗格再把 agent 放進去，agent 穩穩坐在容器裡](/figures/herdr-pane-before-agent.svg)

我用最多的是這一行，意思是「等它卡住需要我的時候再叫我」：

```bash
herdr agent wait reviewer --until blocked --timeout 120000
```

![上下兩條時間線，上面那條密密麻麻插著十幾個空手查看的刻度只有最後一個撞到卡住，下面那條一路空白只在卡住的那一刻亮起一個點](/figures/herdr-poll-versus-wait.svg)

讀回結果有一個天花板：如果 `--lines` 加大還是讀不到完整回答，是因為那個 agent 的畫面捲出去的部分不會留下來。我的做法是叫它把完整回覆寫成一個檔、只回檔案路徑，我再去讀檔。

![一根長條答案穿過窗格上緣，框內那截是讀得到的、框外那截灰掉標著捲出去就沒了，右邊另一條路徑把整根答案寫成檔案再整根讀回](/figures/herdr-alt-screen-scrollback-ceiling.svg)

其他幾個有用的指令，一行一個：

- `herdr notification show "標題" --body "內文"`：跳一個通知。
- `herdr --remote 某台機器`：接到另一台機器上的 herdr，前提是你本來就能用 SSH 連過去。
- `herdr update`：更新。
- `herdr --default-config`：把預設設定整份印出來，想改按鍵或顏色從這裡抄。設定檔的位置，打 `herdr --help` 最後幾行會告訴你。
- `herdr --skill`：印一份給 agent 讀的完整操作手冊。這份比官網完整，而且跟你裝的版本相同。

## 我自己怎麼用

第一個用法是三席對抗。我有一份技術指標的驗證設計，先讓 Codex 讀稿挑毛病，挑了三輪。後來我在 herdr 開三格：一格當設計者、一格當統計對手、一格專門問「這是不是他要的題目」，三格各自跑數字。結果兩格抓到 Codex 三輪都沒抓到的洞。我學到的一句話是：只讀稿的審查抓不到要跑數字才看得見的洞。

第二個是手機接手電腦，前面那篇寫過。herdr 在裡面只是一間關了門人照樣工作的房間。

第三個發生在裝之前。我讀它的文件，借了「卡住是一種獨立狀態」這副眼鏡回頭看自己的電腦，當場抓到一隻掛了五十一小時沒人管的程式。

老實說一句：不是每件事都值得開三格。我評估過三個任務，只有一個值得。另外兩個開了也只是多花錢。

## 新手最常卡的地方

- 裝完打 `herdr` 說找不到：終端機沒重開。關掉再開。
- 按了 ctrl+b 沒反應：要放開再按下一個鍵，不是三個鍵一起按。
- 想開第二個 agent 卻開在同一格：先按 ctrl+b, v 切格，再打 `codex`。
- 側欄上 done 一直不消失：那只是「你還沒看」，點進去看一眼就好。
- Windows 上按 ctrl+b 被終端機吃掉：在設定檔把開頭鍵改成 f12。怎麼改，看 `herdr --default-config` 印出來的 `[keys]` 那段。
- 官網有一頁教你用 npx 裝一份給 agent 讀的手冊，但那份的版本可能跟你裝的不同，語法對不上又不報錯。直接用 `herdr --skill` 印你這個版本的。

Windows 進階兩條，用 SSH 遠端進來的人才會碰到：透過 SSH 進來的視窗看不到捷徑，安裝路徑要寫真實資料夾；Git Bash 會把 `/effort` 這種斜線開頭的字當成路徑，送指令前面加 `MSYS_NO_PATHCONV=1`。

## 帶得走的一件事

我用了一個月之後想到的一件事是：這類工具能不能幫到你，看你能不能先說出哪個 agent 現在在等你。

我自己試過的做法是這樣。今晚裝好之後先不要學按鍵，開兩格各放一個 agent，各派一件小事，然後只看側欄，把每一個的狀態抄在紙上：working、blocked、idle、done、unknown。明天同一時間再抄一次。兩次都寫不出 blocked 是誰，代表你的 agent 還不需要辦公室，先別急著搬家。
